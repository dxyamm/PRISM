# PRISM

PRISM adds three label-efficient scoring branches to frozen Anomaly-Aware Pre-training and Fine-tuning (APF) representations: Normal-conditioned Relational Deviation (NRD), Neighborhood Heterogeneity Profiling (NHP), and Task-Sensitive Metric Contrast (TSMC). The encoder and APF head remain fixed. The added branches use the split's labeled training nodes and an unlabeled reference set, then return corrections in APF margin units.

This repository contains the PRISM scoring code and a small software test. It does not contain APF source, benchmark datasets, pretrained weights, or experiment outputs. Use the official [APF repository](https://github.com/Cloudy1225/APF) for the baseline implementation and follow its license and dataset terms.

## Install

Python 3.9 or later is required. Install the CPU build of PyTorch for a CPU run, or install a CUDA-compatible build using the official [PyTorch installation selector](https://pytorch.org/get-started/locally/).

```bash
python -m venv .venv
```

Activate the environment, then install the package and test tools:

```bash
python -m pip install -e ".[test]"
```

## Run

The scoring command accepts a trusted PyTorch bundle exported from the frozen APF pipeline:

```bash
python run_prism.py apf_bundle.pt prism_scores.pt
```

It fits the three PRISM branches and writes scores for APF and all eight combinations of NRD, NHP, and TSMC. The output contains query node IDs, the fitted models, and a score vector for each configuration. Query labels are not part of the input schema and are never read by the scoring code.

The configuration keys follow this order: the first bit enables NRD, the second enables NHP, and the third enables TSMC.

| Key | Scoring method |
|---|---|
| `000` | APF baseline |
| `100` | APF + NRD |
| `010` | APF + NHP |
| `001` | APF + TSMC |
| `110` | APF + NRD + NHP |
| `101` | APF + NRD + TSMC |
| `011` | APF + NHP + TSMC |
| `111` | Full PRISM |

The `examples/toy_demo.py` script runs the implementation on generated data. Its output checks the software path only and is not a benchmark result.

```bash
python examples/toy_demo.py
pytest
```

## Input bundle

All feature matrices use the same global node order. IDs are zero-based indices into those matrices and the edge list. Training, reference, and query IDs must be disjoint.

```python
bundle = {
    "features": {
        "low": low_embeddings,       # [num_nodes, embedding_dim]
        "high": high_embeddings,     # [num_nodes, embedding_dim]
        "raw": input_features,       # [num_nodes, feature_dim]
        "teacher_gate": apf_gate,    # [num_nodes, embedding_dim]
        "teacher_logits": logits,    # [num_nodes, 2], normal then anomaly
    },
    "embeddings": {
        "low": low_embeddings,
        "high": high_embeddings,
    },
    "edge_index": edge_index,        # [2, num_edges]
    "train_ids": train_ids,
    "train_labels": train_labels,    # 0 = normal, 1 = anomaly
    "reference_ids": reference_ids, # unlabeled calibration nodes
    "query_ids": query_ids,
    "calibration_center": center,   # APF margin mean on reference nodes
    "calibration_scale": scale,     # APF margin standard deviation
}
```

`teacher_gate` and `teacher_logits` must be generated by the same frozen APF head used to create the low/high embeddings. The calibration center and scale must use that head's anomaly-minus-normal margin on the reference nodes. The code expects the reference labels to remain unused by PRISM.

The adapter symmetrizes and deduplicates edges and removes self-loops before calculating NHP descriptors. It accepts an edge list in either direction and does not require DGL. For large graphs, prepare the bundle in the same environment as APF and ensure host memory is sufficient for the feature matrices and sparse adjacency.

## Evaluation protocol

For a paper-protocol run, use the frozen APF encoder and split-specific head, official train/reference/query masks, and the published fixed coefficients: NRD 0.25, NHP 0.1, TSMC 0.1, and TSMC metric strength 0.9. Do not select coefficients or checkpoints with query labels. Run the benchmark evaluator separately after saving all query scores.

The eight-graph study used Reddit, Weibo, Amazon, YelpChi, Tolokers, Questions, T-Finance, and T-Social. For each official mask, the fitting set contained 80 normal and 20 anomalous training nodes, the reference set contained 100 unlabeled validation nodes, and the query set contained the corresponding test nodes. The paper used mask columns 10 through 19.

The public command performs fitting and scoring for one split. Dataset preprocessing, APF training, checkpoint selection, metric aggregation, and benchmark-specific mask loading are intentionally kept in the upstream APF and benchmark workflows. This keeps the PRISM package independent of data licenses and APF's training dependencies.

## Method components

- **NRD** uses normal-conditioned cross-view residuals, class-balanced kernel readouts, and an asymmetric support contrast. A teacher-conditioned projection removes evidence already explained by the frozen APF fused representation and margin.
- **NHP** summarizes coordinate-wise neighborhood dispersion in frozen low- and high-frequency embeddings, then fits a class-balanced readout.
- **TSMC** estimates coordinate relevance from class-balanced squared input gradients and contrasts a learned diagonal metric with a matched isotropic scorer.

The kernel readouts implement these scoring rules; they are not separate claimed contributions. TSMC is computed independently and added using the same APF calibration scale.
